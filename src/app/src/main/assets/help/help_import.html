在本 App 中导入聊天记录

本 App 的导入是追加式：导入的对话并入现有会话库，现有对话全部保留。 从 0.2.1 起，选完 ZIP 后会先弹出会话勾选对话框，可以只导入部分对话 （0.1.4 曾提供该功能，0.2.0 重构时一度移除，现予恢复）。

导入步骤

  1. 在菜单或欢迎页点击「导入 DeepSeek 聊天记录」。
  2. 系统会打开 Android 文件选择器，进入「下载」目录，选择从网页端导出的 deepseek_data-*.zip。
  3. App 读取导出包的会话索引，弹出「选择要导入的对话」列表（默认不选， 点谁选谁）：逐条点击勾选，也可用顶部「全选 / 清空」；按钮会实时显示将导入的 数量，如「导入所选（2）」，未勾选时不可点击，点它只导入勾选的对话。 点「全部导入」则整包追加。
  4. 导入随即开始：App 调用官方解析器读取（筛选后的）导出包并逐个并入会话库， 期间会提示「官方解析中」，请保持页面打开。
  5. 完成后会提示追加了多少个对话，页面自动刷新；回到会话列表即可看到 新旧对话并存。
  6. 打开任一导入的对话发送一条新消息，确认可以收到回复。

追加与覆盖的区别

  • 追加导入（本 App 默认）：官方代码解析导出包后按会话并入本机 会话库，现有对话不受影响。若导出包中的对话与本机某条对话同源（id 相同）， 会以导入侧内容覆盖该条。
  • 覆盖式导入（官方页面自带）：官方页面「设置 → 数据」里的导入 会替换本机全部对话记录。若你想丢弃现有对话、只保留导出包内容，请改用 页面内自带入口。

导入前先备份（建议）

追加导入通常不影响现有数据，但定期备份仍是好习惯：使用「设置 → 数据管理 → 导出全部历史」把当前本地聊天导出为 ZIP，妥善保管（备份不含 API Key）。

导入后发生了什么？

  • 导出的历史内容被并入本 App 的本地会话库；不会写回 DeepSeek 网页端， 也不会恢复网页端原始服务器 session。
  • 导入的内容不等于每次请求都会完整发送给模型；回复可能与原网页端不完全一致。
