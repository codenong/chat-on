# 03｜隐私说明（用户可见文档草稿）

> 用途：应用商店“隐私政策”与应用内“隐私说明”页（`assets/help/help_privacy.html`）
> 的底稿。发布前需按目标运营地区要求补充：运营主体、联系方式、生效日期、
> 个人信息保护法/生成式 AI 服务等适用条款的落地说明。

## 一、我们是谁

「DeepSeek 续聊助手」（工作名）是帮助用户把 DeepSeek 网页端导出的聊天记录导入手机
App 并继续对话的第三方 Android 工具。本应用不是 DeepSeek 官方产品，与 DeepSeek
官方无关联；应用名称中的 “DeepSeek” 仅用于说明用途。

## 二、数据存在哪里

| 数据 | 存储位置 | 生命周期 |
|---|---|---|
| 聊天记录与附件 | 你的手机，本应用私有存储（IndexedDB） | 随应用存在；卸载或清除应用数据时删除 |
| API Key | 你的手机，Android Keystore 加密保护的密文 | 你删除或卸载时删除；不进入云备份 |
| 应用设置（语言、主题等） | 你的手机，本应用私有存储 | 随应用存在 |
| 聊天备份（你主动导出） | 你选择的位置（如下载目录） | 由你管理；不包含 API Key 和设置 |

本应用没有自有服务器。开发者不运营任何接收你聊天数据的服务。

## 三、哪些数据会发送到 DeepSeek API

当你发送消息、上传附件或使用语音功能时，为生成回复所必需的内容会提交到你配置的
DeepSeek API 服务（api.deepseek.com），包括：

- 本轮问题与系统提示；
- 实际随请求发送的历史上下文（对话越长，输入上下文可能越多）；
- 你主动上传的附件内容。

导入了很长的历史记录，不代表每次请求都会把全部历史发送给模型；客户端受上下文窗口
和上下文组织策略限制。API 费用按 token 计费，由你的 DeepSeek API 账户直接承担，
本应用不代充值、不代收费用。

## 四、开发者收集什么

- 第一版不接入任何统计、埋点、广告或崩溃上报 SDK；
- 开发者不收集、不中转、不存储你的聊天内容、附件或 API Key；
- 应用日志只在本机生成，且不包含完整 Key、聊天正文或附件内容；
- 联网请求仅为两类：加载 APK 内打包的页面资源（不产生网络流量）与调用你配置的
  DeepSeek API。

## 五、你的控制权

- **随时更换或删除 API Key**：应用菜单 → 设置 / 更换 API Key → 删除已保存的 Key；
- **随时导出备份**：设置 → 数据管理 → 导出全部历史（备份不含 API Key）；
- **随时删除全部本地聊天**：设置 → 数据管理 → 删除所有对话（上游功能）；
- **卸载即删除**：卸载应用或清除应用数据会删除本地聊天、附件与 API Key 密文；
  云端 API 账户与已产生的用量账单不受影响。

## 六、安全措施摘要

- API Key 以 Android Keystore 的 AES-256-GCM 主密钥加密后存储，明文不落盘、不进日志；
- 页面只加载随 APK 打包的资源，运行在受信任的本地 origin 下；
- 原生与页面之间的通信桥只对可信 origin 开放，非可信页面无法调用；
- 系统云备份规则已排除密钥存储文件。

## 七、第三方组件与许可

- 壳层代码与依赖：AndroidX（Apache-2.0）、Material Components（Apache-2.0）、
  WebViewCompat（Apache-2.0）；上游 dist 目录内保留其 LICENSE。

指导下进行，并遵守目标运营地区的相关规定。
