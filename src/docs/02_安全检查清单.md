## 六、已知限制（如实告知）

1. Key 以明文形式存在于页面 JS 内存中（与上游在浏览器中运行时一致）；已保证不落
   localStorage、不进日志、不进备份。若设备被 root 或存在恶意输入法，仍有被读取的理论风险。
2. 导入开始后能否中途取消取决于上游导入器能力；壳层在确认框阶段支持取消，并提示
   “导入期间请保持 App 打开”。
3. WebView 内导出超过 400 MB 时提示改用桌面浏览器（`MAX_EXPORT_BYTES`）。
4. 备份恢复依赖上游导入器对自有导出格式的兼容性，列入 `docs/04_测试与验收.md` 用例 H4。
