在本 App 中导入聊天记录

导入步骤

  1. 在菜单或欢迎页点击「导入 DeepSeek 聊天记录」。
  2. 系统会打开 Android 文件选择器，进入「下载」目录，选择从网页端导出的 deepseek_data-*.zip。
  3. 确认文件名后，仔细阅读导入提示：导入可能替换本机当前保存的聊天记录和附件。
  4. 如果本机已有聊天数据，建议先备份（见下文）。确认后点击「开始导入」。
  5. 页面会再弹出官方确认框，确认后开始导入；文件较大时请耐心等待。
  6. 导入期间请保持 App 打开，尽量不要强制关闭。
  7. 完成后回到会话列表，找到原来的对话并打开，发送一条新消息确认可以收到回复。

导入前先备份

使用「设置 → 数据管理 → 导出全部历史」把当前本地聊天导出为 ZIP；之后如需恢复， 再用「导入 DeepSeek 聊天记录」选择该文件（导入是覆盖操作）。

导入后发生了什么？

  • 导出的历史内容被导入到本 App 的本地会话库；不会写回 DeepSeek 网页端， 也不会恢复网页端原始服务器 session。
  • 导入的内容不等于每次请求都会完整发送给模型；回复可能与原网页端不完全一致。

常见问题

现象说明与处理
提示无法识别文件请确认是从 DeepSeek 网页端导出的原始 ZIP；重新导出，不要解压或重新压缩。
导入后看不到旧对话导入完成后回到会话列表刷新查看；长历史可能需要稍等加载。
导入中断重新执行导入；导入期间保持 App 前台，避免省电策略杀进程。
发送消息没有回复先确认已配置有效 API Key、API 账户有余额、网络可用。
